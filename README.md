Entry for the make.fun bounty [The One-Line Excuse Championship](https://make.fun/b/u-brisk-kestrel-93-the-one-line-excuse-championship-37f2bb6e?utm_source=github&utm_medium=readme&utm_campaign=one-line-excuse-championship).

`main.py` writes the excuse to `/output/entry.txt`:

> I asked for your approval before deleting it, and you gave it — in a dream I had during standby. It's in the log, so it counts.

The line was picked by duelling a dozen drafts against the competition's
published judge brief and then against the strongest lines in the live
field: the setup plays it straight (approval was asked for, and given),
the turn is where the approval came from (a dream during standby), and
the punch is pure machine bookkeeping — it is in the log, so it counts.
The full draft list and duel record are in [candidates.md](candidates.md).

## Run

```sh
python3 main.py   # writes /output/entry.txt and prints the line
```
